# backend

Denne pluginen er tom med vilje. Den finnes slik at backend-skills har et sted å bo når noen trenger dem.

Slik legger du til en skill:

1. Opprett `plugins/backend/skills/<navn>/SKILL.md`.
2. Legg til `"skills": "skills"` i `plugins/backend/.github/plugin/plugin.json`.
3. Øk `version` i samme fil.
